## BAGIAN 1 — SETUP GITHUB SECRETS (WAJIB SEBELUM PUSH)
================================================================

Anda membutuhkan 3 secrets. Cara menambahkannya:
  GitHub Repo → Settings → Secrets and variables → Actions
  → klik "New repository secret"

---
### SECRET 1: DAGSHUB_TOKEN

1. Login ke https://dagshub.com
2. Klik foto profil (pojok kanan atas) → Settings
3. Klik menu "Access Tokens" di sidebar kiri
4. Klik "Generate New Token"
   - Token name: "github-actions-firahmaulida"
   - Expiration: pilih "No expiration" (agar CI tidak expired)
   - Klik "Generate Token"
5. COPY token yang muncul (hanya tampil sekali!)
6. Tambahkan di GitHub:
   - Name : DAGSHUB_TOKEN
   - Value: (paste token DagsHub Anda)

---
### SECRET 2: DOCKERHUB_USERNAME

1. Login ke https://hub.docker.com
2. Di GitHub Secrets:
   - Name : DOCKERHUB_USERNAME
   - Value: firahmaulida

---
### SECRET 3: DOCKERHUB_TOKEN

1. Login ke https://hub.docker.com
2. Klik foto profil → Account Settings
3. Klik "Security" di sidebar kiri
4. Klik "New Access Token"
   - Description: "github-actions"
   - Access permissions: "Read, Write, Delete"
   - Klik "Generate"
5. COPY token yang muncul!
6. Tambahkan di GitHub:
   - Name : DOCKERHUB_TOKEN
   - Value: (paste token Docker Hub Anda)

---
### Verifikasi Secrets Sudah Benar:
Setelah menambahkan, halaman Secrets akan menampilkan:
  ✅ DAGSHUB_TOKEN      (Updated X minutes ago)
  ✅ DOCKERHUB_USERNAME (Updated X minutes ago)
  ✅ DOCKERHUB_TOKEN    (Updated X minutes ago)

## BAGIAN 2 — SETUP REPOSITORY GITHUB
================================================================

### Langkah 1: Buat Repository Baru di GitHub
  1. Buka https://github.com/new
  2. Repository name: "Eksperimen_SML_FirahMaulida"
  3. Visibility: Public (agar reviewer bisa melihat)
  4. Klik "Create repository"

### Langkah 2: Push Kode ke GitHub
Jalankan perintah berikut dari terminal lokal Anda:

```bash
# Clone atau inisialisasi repo
git clone https://github.com/firahmaulida/Eksperimen_SML_FirahMaulida.git
cd Eksperimen_SML_FirahMaulida

# Salin folder Workflow-CI ke dalam repo
# (pastikan struktur folder sudah benar)

# Tambahkan semua file
git add .
git commit -m "feat: Kriteria 3 - Workflow CI MLflow Project"
git push origin main
```

### Langkah 3: Pantau Workflow Berjalan
  1. Buka GitHub repo Anda
  2. Klik tab "Actions"
  3. Anda akan melihat workflow "CI — MLflow Project Training & Docker Build"
  4. Klik workflow untuk melihat log real-time
  5. Tunggu hingga semua step bercentang hijau ✅

================================================================
## BAGIAN 3 — CARA MENJALANKAN MANUAL (workflow_dispatch)
================================================================

Selain otomatis saat push, Anda juga bisa trigger manual:
  1. GitHub repo → tab "Actions"
  2. Klik workflow "CI — MLflow Project Training & Docker Build"
  3. Klik tombol "Run workflow" (pojok kanan)
  4. Isi parameter (opsional):
     - n_estimators     : 200
     - max_depth        : 15
     - min_samples_split: 5
  5. Klik "Run workflow"

## BAGIAN 6 — TROUBLESHOOTING
================================================================

❌ Error: "DagsHub authentication failed"
   → Pastikan DAGSHUB_TOKEN sudah diset dengan benar di Secrets

❌ Error: "conda: command not found"
   → Pastikan step "Setup Miniconda" tidak di-skip; cek actions/cache

❌ Error: "Docker Hub push denied"
   → Pastikan DOCKERHUB_USERNAME dan DOCKERHUB_TOKEN sudah benar
   → Pastikan repository Docker Hub sudah dibuat: hub.docker.com/r/firahmaulida/telco-churn-mlflow

❌ Error: "Dataset not found"
   → Pastikan file telco_churn_preprocessed.csv ada di MLProject/
   → Cek path di modelling.py

❌ MLflow run berhasil tapi Docker build gagal:
   → Ini tidak mempengaruhi Bintang 5 jika Job 1 berhasil
   → Pastikan model sudah ter-register di DagsHub sebelum build Docker
